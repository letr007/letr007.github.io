浅谈Agent

本文最后更新于 2026-11-26T09:33:22+00:00

今天来谈谈 Agent。我认为 Agent 翻译为智能体是极为恰当的。至少当下如此。

什么是智能？一般认为，一个系统为了达成目标，理解环境，学习经验，进行推理，并根据变化采取合适行动的能力就是智能。

什么是体？体是一个整体，是系统工程。前面智能的定义中强调了，一个系统，体指的就是这个系统。

对于当下 llm-based 的 Agent，核心是 LLM（Large-Language-Model）。llm 有智能吗？有。

llm 可以根据用户的输入，理解需求，利用训练时获得的知识和能力，结合当前上下文进行推理，最后得到结果。但显然，这种智能被限制于模型内，我们只能够与其对话，而llm 无法做到任何需要与模型之外的世界交互的事情。比如点一杯奶茶，写一个文件。能做到的最多是陪你聊聊天解解闷，或者生成散落的代码，交给你cv（ctrl-c，ctrl-v）。

那 Agent 呢？从一个最基础的 chat loop 看，在一个循环中，接收用户输入，模型进行推理，给出结果。

它智能吗？会是个不错的陪聊

开始变成 Agent 的，是 tool 进入 loop。就像人类使用工具一样，通过调用工具，llm开始可以感知到环境，取得自己需要的信息，持续推理，并借助合适的工具来反向改变环境。

它有智能吗？是的，它有智能。

最大的改变是，llm 拥有了与外界交互的能力。而后续围绕 Agent 的所有加料，skill，mcp，权限控制，上下文管理，压缩，记忆，等等，目标是为了构建一个可运行、边界清晰的工程系统。

在当下 llm-based 的 Agent 中，llm 就是 Agent 的大脑，而 Agent 才是完整的“体”。llm 位于 Agent 中，便有了认识世界改变世界的能力。

Agent 是一个系统工程。

除了 llm 外，单独的每个模块似乎都没什么智能可言，但组合起来成为 Agent 后，便可以写代码，陪聊天，改文档，甚至操作你的电脑，替你完成任务。显然，整体有了智能。而且能够完成比以前更多的任务，可以说智能水平“更高”了。

那模型变得更加强大了，Agnet还有存在的必要吗？我认为是有的，而且很有必要。

以后或许不会叫harness，不会称之为Agent，但不变的是，模型总是需要一套系统，来提供与外界系统交互的能力。模型能力的发展并不能打破维度隔阂，而 Agent 正是解放模型能力，让虚拟影响现实的桥梁。早期，Agent 或许真的是为瘸子加义肢，但现在，Agent 已发展为不可或缺的身体。

因为系统，所以智能。智能不只存于个体，也可以在系统中呈现。

杂谈
